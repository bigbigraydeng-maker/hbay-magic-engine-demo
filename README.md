# HBay — Magic Engine Design Demo

Responsive client-review demo for HBay Water.

- Home: `design/index.html`
- Design rationale and review scope: `design/review.html`
- Water source editorial: `design/our-water.html`
- Supplied document previews: `design/reports.html`

This is a design demonstration, not the completed production website. SEO, GEO, sitemap, Google Search Console, GA4, Google Tag Manager and online enquiry handling have not been completed. Pages include noindex metadata.

Deploy with GitHub Pages from the main branch root. No build step is required.
